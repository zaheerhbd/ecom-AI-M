Phase 4: the assistant now has a screen

A new Assistant section in the website lets you chat with the agent and see exactly how each answer was made: every safety check, AI call and tool call, with tokens, time and cost. It also has pages to browse past answers and to run the automatic tests.

The point of the screen: when an answer is wrong, you can see why by clicking it. Wrong tool? Wrong filter? A safety check blocked it? The AI ignored the tool's result? Each step shows exactly what went in and what came out.

The Chat page

Messages on the left. On the right, "How this answer was made" for the answer you clicked (the latest one by default).

  • Suggested questions to start with, a character counter (2,000 limit), Enter to send, Shift+Enter for a new line.
  • Remembers the conversation: a follow-up "Which of those is the cheapest?" correctly answered "the $12 Alpine Forge Comet Summit Glove". A page reload keeps the chat (this browser tab only); New chat starts again.
  • Shows whether you're logged in. Logged in, the order tools work; not logged in, it says order questions need a login.
  • Friendly errors: too many messages (429) shows "Too many messages, please wait a minute"; a server that can't be reached says so.
  • Answers are shown with simple formatting (bold, bullet lists) the way the AI wrote them.

The Runs pages

Every answer ever given (kept for 30 days), newest first, with totals at the top. Click a row to open its full timeline: the same panel as on the Chat page.

Test runs' answers are marked test so you can tell them apart from real chats.

The Evals page

Start an automatic test run, watch it progress, and see each case's checks.

  • Starts small on purpose: the default is the 3-case quick check. You can also pick one category, type case ids, or run all 51. "All" warns you and needs a tick to confirm.
  • Shows how many AI conversations a run will start before you press the button.
  • Progress bar while it runs (the page checks every 3 seconds), then pass rate, right-tool rate, flaky cases, median/p95 time and cost.
  • Earlier runs listed on the left; click one to see it again.

How it works page

A plain-English explanation for anyone using the shop: the six steps of an answer, a diagram of the loop, why it's safe, plus a live panel (from api/agent/info) with the current model, limits and the 7 tools with their descriptions.

Design choices and why

Same pattern as the shop

A lazy-loaded AgentModule at /agent, like shop and orders, using the same Bootstrap theme, breadcrumbs and pager.

Why: nothing new to learn, and the assistant's code only downloads when someone opens it.

One timeline, used twice

AgentTimelineComponent shows a chat answer and a saved run the same way.

Why: one place to improve; and what you see live is exactly what you'll see later in Runs.

No full-screen spinner for the assistant

The shop's "Loading…" overlay is skipped for /agent/ calls; the chat shows "thinking…", the evals page a progress bar.

Why: an answer can take 2–60 seconds on Gemini's free tier; a full-screen overlay would hide the chat, and polling would make it flash every 3 seconds.

AI text is escaped before formatting

The small Markdown formatter turns everything into plain text first, then adds bold/lists.

Why: the AI's answer can never inject its own HTML or scripts into the page. Angular's sanitiser is a second safety net.

Admin pages fail politely

In production, Runs and Evals need the Admin role (the API enforces it). The pages show "admins only" or "please log in" instead of breaking.

Why: the security is on the server; the screen just explains it.

Chat kept per browser tab

The conversation and its session id are kept in sessionStorage.

Why: a reload doesn't lose the chat, but closing the tab does, and nothing personal is kept long-term in the browser.

How to try it yourself

  1. Docker Desktop on, then the API: cd API; dotnet run.
  2. The website with Node 16 (from client/): $env:PATH = "$env:NVM_HOME\v16.20.2;$env:PATH"; node node_modules\@angular\cli\bin\ng serve
  3. Open https://localhost:4200 → Assistant in the top menu. (If products don't load, open https://localhost:5001/swagger once and accept the certificate warning.)
  4. Click a suggested question, then click the answer to explore its steps.
  5. Log in as bob@test.com / Pa$$w0rd and ask "Show me my orders".
  6. Evals tab → Start test run (quick check, 3 cases, free on Gemini).

Things I noticed

  • Gemini's free tier is slow at times: answers took 2 to 60 seconds (one AI call alone took 32 s). The screen handles it with "thinking…", but for a demo OpenAI is much faster (switch Agent:Llm:Provider).
  • An old test answer was repeated twice ("I can help with that, but you'll need to sign in first." ×2) in a 2026-11-21 run on OpenAI. Today's runs don't show it. Worth a look in Phase 5.
  • The "Runs" totals include test runs as well as real chats. Fine for now; a filter could come later.
