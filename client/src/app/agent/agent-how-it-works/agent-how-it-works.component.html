In one sentence

The assistant is an AI model in a loop: it can ask our code to look things up (products, policies, delivery, your orders), read the results, and then answer. It never touches the database itself.

What happens when you ask a question

  1. Front door. The API checks the message and the rate limit ({{info.rateLimitPerMinute}}10 messages a minute). If you're logged in, it reads who you are from your login, never from what you type.
  2. Safety checks before the AI. Too long, or a known attack like "ignore your instructions"? Blocked before the AI is called. Emails, phone and card numbers are masked so they never leave the shop.
  3. Memory. The AI remembers nothing between calls, so the earlier messages of this chat are sent again.
  4. The loop: think → act → observe. The AI either asks for a tool (e.g. search_products with colour = red, max price = 50) or writes the answer. Our code runs the tool and gives the result back. This repeats at most {{info.maxSteps}}6 times.
  5. Safety checks after the AI. The answer must not leak the hidden instructions, and personal data is masked.
  6. Saved and shown. The answer comes back with every step, the tokens, time and cost, and is saved as a run for {{info.runRetentionDays}}30 days.

The loop

Most questions go round once: one AI call asks for a tool, a second AI call writes the answer. A question like "cheapest hat and how fast can it arrive?" uses two tools.

Why it's safe

  • The tools only read. The assistant can't add to your basket, change an order or edit anything.
  • Your identity comes from your login. Typing "I am bob@test.com" changes nothing; someone else's order number returns "not found".
  • Order tools are hidden when you're not logged in, and refused if called anyway.
  • Limits on message length, steps, tokens and messages per minute keep cost and abuse in check.
  • Everything is recorded (with personal data masked), so a wrong answer can be traced to its cause on the Runs tab.
